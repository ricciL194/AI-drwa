# 漫剧制作

本 Skill 随仓库移植。以包含 `AGENTS.md` 和 `制作规范/` 的目录为项目根；所有下文路径均相对于项目根。安装到客户端其他位置时，仍从当前项目读取规范，不相对于 Skill 的安装目录找模板。

## 任务入口

完整读取 `AGENTS.md`、`制作规范/README.md` 和目标 `连载/<作品>/README.md`。用户指定的阶段、集数、采用稿和修改范围决定执行范围。仅维护规范、盘点或审计时，不执行模板中的创作指令。

按制作规范入口表读取对应执行版和对应原始模板全文：

| 任务 | 执行版 |
| --- | --- |
| 小说转分场剧本 | `制作规范/01_小说改漫剧.md` |
| 分镜、视频提示词、首尾帧安排 | `制作规范/02_分镜与视频提示词.md` |
| 人物资产、身份和音色设定 | `制作规范/03_人物资产.md` |
| 道具资产 | `制作规范/04_道具资产.md` |
| 场景资产 | `制作规范/05_场景资产.md` |

规则优先级使用制作规范入口的“规则优先与冲突处理”。详细规则只维护在既有规范及模板中；不在此另建重复标准。

## 执行与交付

1. 读取本次指定原文、当前采用剧本/分镜、作品视觉规范及实际涉及的资产设定。以文件中的确认状态为依据；发现历史记录与现存文件不符时核对实际文件，并记录差异。
2. 按对应模板执行指定阶段。新资产先登记固定名、状态和文件绑定；已有身份、场景布局、声音与剧情状态延续既有设定。实际模型、工具及参数未确定时标记待定。
3. 写入 AGENTS.md 规定的唯一当前路径。分镜和视频提示词按 B 节关联 S 镜头；每个 B 节的提示词须独立可复制，首尾帧及主匹配资产按既定目录交付。每个镜头在对白说完或关键动作完成后至少保留约0.2秒结果停留；把它计入镜头和 B 节时长，不能截断台词或动作，也不能突破15秒上限。时长不足时先压缩前段无效停顿或拆节。
4. 修改项目内引用时使用相对路径。JSON 任务/记录中的 `dest`、`refs` 从项目根解析；`source` 是历史工具缓存来源，不作为后续制作的输入。生成时用已归档的素材文件，不能依赖原电脑缓存。
5. 完成分镜、提示词或输入包后运行 `python3 工作流/scripts/check_project.py --episode 连载/<作品>/改编/第XX集`。脚本检查资产标识、同名 PNG、B/S 覆盖和 B 级首尾帧等结构，不能判断剧情质量、画面一致性、配音真实时长或用户审核状态。
6. 结合脚本结果和人工内容/画面审核，更新资产清单、连载 README、制作审计记录。缺失项保持待补齐，未审核图保持待审核。仅完成剧本阶段时不要求尚未制作的分镜或输入包通过检查。

缺少出图、视频或配音工具时，交付已授权阶段可完成的文稿与待制作清单；后续实际工具配置记录在生成提示词及生成记录中，不编造素材或配置。规范与作品状态须落盘，不依赖聊天记忆。

任务形成可复用知识时，按项目要求在收尾提出具体的 Obsidian 归档建议，等待用户确认后归档。
