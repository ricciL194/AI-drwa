# AI-drwa 首个公开版本清单

## 公开保留

- `README.md`
- `AGENTS.md`
- `.agents/skills/manju-production/SKILL.md`
- `制作规范/`
- `工作流/`
- `.github/`、`.gitignore`、`.gitattributes`、`LICENSE`

这些文件用于说明项目规则、模板、可移植工作方式和结构检查入口。

## 本机保留

- `连载/` 下的正文、剧本、分镜脚本和生成提示词
- 角色、道具、场景和镜头图片
- 视频输入包、首尾帧、样片、音频、字幕、剪辑工程和成片
- 生成记录及其历史素材索引

上述内容属于制作档案，已由根目录 `.gitignore` 排除。它们仍保留在当前工作区，供本机继续制作和审计；公开仓库不会包含这些内容。

## 发布前检查

```sh
git status --short --ignored
git check-ignore -v 连载/极寒纪元/改编/第03集/分镜脚本.md
git check-ignore -v 连载/极寒纪元/制作/第03集/视频输入/EP03_整集输入/素材/陈野.png
python3 工作流/scripts/check_project.py
```

只有公开保留项应进入首个 Git 提交。若以后需要公开某一集，应先单独确认该集的文字、图片、音视频及第三方素材授权，再用明确的例外规则逐项加入。
